# DNA Sequence Analyzer

A beginner Python project that analyzes a DNA sequence entered by the user. I created this project to practice connecting Python programming with my interest in bioinformatics.

## Features
- Validates DNA sequences using A, T, C, and G
- Counts each nucleotide
- Calculates GC content
- Generates a reverse complement
- Counts codons in groups of three bases
- Saves results to a text report

## How to Run
1. Download `dna_analyzer.py`
2. Run the program using Python
3. Enter a DNA sequence when prompted, such as:

```text
ATGCGATACGTTAGC
```
4. View the results in the Python window and in the generated `dna_report.txt` file

## Example Concepts Used
- Python functions
- Dictionaries
- `for` loops
- `if` / `elif` / `else` statements
- String methods
- File writing

I am a Computer Science student interested in bioinformatics. This project helped me practice using Python to work with DNA-related data, including nucleotide counts, GC content, reverse complements, and codons.
